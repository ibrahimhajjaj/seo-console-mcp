description: Find content to create or improve, backed by Search Console evidence
argument-hint: "[siteUrl e.g. sc-domain:example.com]"
---

For the Search Console property `$ARGUMENTS`, find what content to create or improve.

1. Run `search_opportunities` for keywords ranking just off page one (positions 5-20) with real impressions.
2. Run `ctr_gaps` for pages and queries under-performing the click-through rate expected at their position.
3. Run `query_cannibalization` for queries where more than one page competes.

Group the recommendations into **create new** versus **improve existing**. For each, include the query, the current position, and the impressions that justify acting on it, and rank by likely traffic gain. Be concrete: name the page to change or the page to write.
