---
description: Find content to create or improve, backed by Search Console evidence
argument-hint: "[siteUrl e.g. sc-domain:example.com]"
---

For the Search Console property `$ARGUMENTS`, find what content to create or improve.

1. Run `search_opportunities` for keywords ranking just off page one (positions 5-20) with real impressions.
2. Run `ctr_gaps` for pages and queries under-performing the click-through rate expected at their position.
3. Run `query_cannibalization` for queries where more than one page competes.
4. Run `keyword_ideas` for net-new keyword and question ideas, passing the property as `siteUrl` so each idea is cross-referenced against current rankings.

5. If this product also ships on the App Store, Google Play or WordPress.org, run `app_store_listing`, `play_store_stats` or `wporg_plugin`. Search is one of four places it gets found, and the store listing has its own indexed fields and its own conversion rate.

Group the recommendations into **create new** versus **improve existing**. For each Search Console-backed recommendation, include the query, the current position, and the impressions that justify acting on it, and rank by likely traffic gain. Be concrete: name the page to change or the page to write.
